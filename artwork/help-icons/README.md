## Master policy

All icons in `hires/` are the canonical, resolution-independent originals for this visual family. They use a 2048×2048 SVG canvas with transparent background and are kept in the canonical `TheDaimos/gewitterradar` repository. The test build embeds browser-rendered derivatives of these masters; the original artwork remains untouched.
