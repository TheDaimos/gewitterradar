# Gewitterradar V4.09.06 – Test Release Notes

Status: **DEV/Testkandidat · nicht veröffentlicht**  
Datum: **20.09.2026**  
Öffentliche Rückfallbasis: **V4.08 FINAL / native Integration 0.20.0**

## Neu

- Standort-Pille im Vollbild frei verschiebbar auf Desktop, Android und iPad/iPad Pro.
- Position lokal und normalisiert gespeichert.
- Standortmenü öffnet oben bevorzugt nach unten und unten bevorzugt nach oben.
- Im mittleren Bereich wird bei verfügbarer Breite mehrspaltig dargestellt.
- Wenn die Liste in der bevorzugten Richtung einspaltig nicht vollständig passt, wird automatisch auf mehrere Spalten erweitert.
- Geöffnete Standortliste ordnet sich während des Verschiebens der Pille live neu an.
- Interner Scroll der Liste bleibt der letzte Fallback.
- Separate Fensterkennung: `40906`.
