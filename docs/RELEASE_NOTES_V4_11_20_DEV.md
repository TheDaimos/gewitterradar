# Gewitterradar V4.11.20 DEV

Stand: **2026-10-07**

## Darstellungsmenü kompakter

Der erste Realtest von V4.11.19 zeigte, dass die Auswahlfelder im schwebenden Darstellungsmenü noch zu breit waren.

V4.11.20 verkleinert deshalb ausschließlich die Bedienelemente im schwebenden Kartenmenü:

- Darstellungs-Dropdown ca. **150 px**
- Legendenfelder ca. **64 px** je Schaltfläche
- schwebendes Menü wieder schmaler
- mobile Breiten entsprechend angepasst

Die Einstellungen bleiben davon unabhängig.

Unverändert:
- Auto-Zoominterpolation
- Präzise / Ausgewogen / Weich
- Transparenz
- WeatherRouter-Routing
- Leaflet-Transformationen
- Touch-/Pan-/Pinch-Zoom
