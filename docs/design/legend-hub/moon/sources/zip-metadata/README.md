# Legend Hub – Mondfamilie

Master: `leuchtender_vollmond_mit_kratern_und_halo.png` (allererste Vollmondversion).

Die sieben weiteren Phasen wurden aus derselben Bildoberfläche mittels sphärischer Beleuchtungsmaske abgeleitet. Das Vollmondbild ist unverändert übernommen.

Alle Phasen: PNG RGBA mit transparentem Hintergrund, 1254×1254 Pixel; zusätzliche 512×512-Versionen. Nordhalbkugel/Standardorientierung: zunehmender Mond rechts beleuchtet, abnehmender links.

Illumination nach Sonnen-Mond-Phasenwinkel; die tatsächliche Phase und Ausrichtung am Ort und Datum muss die Anwendung berechnen. Die Phasen sind visuelle Klassen, keine astronomischen Echtzeitaufnahmen. Nicht als Berechnungsgrundlage für Mondaufgang, -untergang oder Zeitpunkt des nächsten Phasenwechsels verwenden.

Hinweis: Die Aura ist künstlerisch, nicht astronomisch. Im UI reduzierte Bewegung und Kontrastprüfung auf hellen/dunklen Kartenhintergründen vorsehen.
